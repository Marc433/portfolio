Tiris

In a world ravaged by the Emerald Plague, death is not the end... it’s only the beginning of corruption. In Tiris, you embody Liria, an alchemist and sorceress determined to defy death itself to save her beloved Narcis, turned into an abomination in the service of a dark Necromancer. Face hordes of infected, solve ancient puzzles, and unravel the cursed secrets of a disgraced cathedral.

Soul Pickup: Increases player's souls, which can be consumed to heal.

Pickup & Inventory System

There are 9 different pickups in total, each explained in the slider on the left. These can either be already placed in the map or dropped dynamically via the DropComponent. This component is used by enemies or destructibles, allowing full control over the type of pickups that can be dropped and their drop probability (including the chance of dropping nothing).

The InventoryComponent manages the player’s collected pickups, registering and enabling logic for usage, stacking and consumption of each item.

Melee Enemy: Chases the player and performs short-range attacks.

Enemy AI System

All enemy types are powered by Behavior Trees and AIPerception with visual sensing. Detection radius is smaller behind the enemy, simulating vision cones. Enemies inherit from a shared EnemyBase class, which defines health, movement, and damage logic.

There are 3 archetypes: melee, ranged, and explosive, each with their own behaviors and abilities.

Tutorial Box: Shows keyboard or controller buttons depending on current input.

Dynamic UI & Video Playback

The tutorial boxes are context-sensitive prompts that automatically adapt their appearance based on the player's current input method — keyboard & mouse or gamepad. This ensures clarity and fluid tutorials for both control schemes.

Meanwhile, videos such as logos and intro cutscenes were seamlessly integrated using Unreal's MediaPlayer system. This allows in-game video playback, audio sync, and transitions to be fully controlled via C++ or Blueprints.

Steam Achievements Integration

All 17 achievements were integrated using the Steam Online Subsystem and a custom Achievement Subsystem. The system handles initialization, caching, progress tracking, and communication with the Steam backend.

Progress-based achievements are updated using a stat-based system and unlocked when specific thresholds are met. Logic is encapsulated in TDAchievementSubsystem and TDSteamAchievements, ensuring achievements persist across sessions.

Raftel's Documentation

Raftel Engine

Together with Carlos Mazcuñán Blanes, I’ve built Raftel Engine, a custom graphics engine in C++ and OpenGL crafted for maximum versatility and performance.

It supports both forward and deferred rendering pipelines, HDR lighting, and fully configurable bloom, enabling cinematic visuals and optimal performance across diverse scenes.

The engine’s PBR materials simulate realistic metalness and roughness, while a robust 3D physics system handles gravity and collision for both static and dynamic entities.

To simplify development, we implemented an Entity Component System (ECS), and built an in-engine editor using Dear ImGui, allowing designers and developers to spawn and configure entities at runtime—adding meshes, lights, physics properties, and working with input binding in real time.

The engine also integrates a flexible Input System, enabling seamless switching between keyboard, mouse, and controller inputs during gameplay.
